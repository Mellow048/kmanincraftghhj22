# Inflation Explained Using Minecraft

> **8-Beat Loop Explainer (`Topics/Explainer/STUDY-NAPOLEON-EXPLAINER.md`):**
> - **Character 1 (`CitizenLead` — Miles):** Hardworking server baker/miner who buys one loaf of bread a day.
> - **Character 2 (`EliteLead` — Sterling):** Server President who solves an emerald shortage by printing 10,000 emeralds.
> - **Loop (`8.loop` -> `1.hook`):** Ends mid-clause (`"...for the exact same loaf, and that's"`) on the exact Frame-0 price-explosion shot.

```narration
# clip 01-hook

[2.miles]     Miles mines all morning, buys a loaf, and goes home happy.
[3.crisis]    Then a dry summer hits, and players run short on emeralds.

[6.jump]      Yesterday one loaf cost one emerald. Today the tag jumps to ten.
```
